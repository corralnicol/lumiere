# Lumiere Scripts

We developed some scripts to help with development and testing. You can find them in this directory.

To install dependencies:

```bash
bun i
```

To run:

```bash
bun run <script-name>
```

This project was created using `bun init` in bun v1.3.12. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
